# Ethik trainieren

Eine kleine Lernseite zum Trainieren vor der Ethik-Probe (5./6. Klasse).
Themen: Glück haben und glücklich sein, Glücksgefühle und Gehirn, materielles und immaterielles Glück,
die drei Arten von Zeit, Freizeit, Freundschaft und Ich-Botschaften.

- Aufgaben zum Ankreuzen, Zuordnen, Lückentext und Selbst-Vergleichen, mit sofortiger Rückmeldung
- Mini-Probe mit 10 gemischten Aufgaben und Übungs-Note
- Keine Anmeldung, keine Namen: Der Fortschritt bleibt nur im Browser des jeweiligen Geräts

Die Seite besteht aus einer einzigen Datei (`index.html`) und läuft ohne Server direkt im Browser.
